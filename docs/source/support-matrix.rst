Support Matrix
==============

Supported Bash versions
^^^^^^^^^^^^^^^^^^^^^^^

The following is a list of Bash versions that are currently supported by Bats and verified through automated tests:

  * 3.2 (macOS's highest bundled version)
  * 4.0, 4.1, 4.2, 4.3, 4.4, and the latest 4.x release
  * 5.0, 5.1, and the latest 5.x release

Supported Operating systems
^^^^^^^^^^^^^^^^^^^^^^^^^^^

The following Operating Systems are supported and tested automatically (CI) or manually during development:

 * Linux: Alpine (CI), AlmaLinux 10 (CI), Arch Linux (manual), Ubuntu 22.04/24.04/26.04 (CI)
 * FreeBSD (CI)
 * macOS: 15 (CI), 26 (CI)
 * Windows: Server 2022 (CI), Server 2025 (CI), 10 (manual)

   * Git for Windows Bash (MSYS2 based)
   * Windows Subsystem for Linux
   * MSYS2
   * Cygwin
